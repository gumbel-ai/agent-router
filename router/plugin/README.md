# Agent Router

See native Claude Code and Codex sessions and subagents and Router-controlled OpenCode, Codex, or Claude Code children in one local terminal view. Track the spawning session, task, exact model, observed state, activity, and elapsed time. Router-launched children also report tokens and estimated cost; for native sessions, use Langfuse for content, per-call usage, and cost. Native agents remain owned by their CLI; Router controls only the children it launches. Native Codex observation needs Router's Codex plugin with its hooks trusted in Codex (`/hooks`); Router-launched Codex children have native delegation disabled.

Run `router setup` after installing the Agent Router runtime. It installs the CLI and registers plugin marketplaces; on macOS the approved setup also installs the background service. Linux daemon startup is manual with `router daemon start`. Setup does not newly enable observation globally. Run `router enable` separately in each project to install Claude's plugin at project scope and write the marker and both clients' project configuration. Commit those files and start fresh sessions. Codex requires project trust, an installed plugin cache, and manual hook trust through `/hooks`. Router never writes hook trust. An explicit `CODEX_HOME` is honored; other homes are not discovered.

Delegation is a separate opt-in. `router init` configures OpenCode with explicit allow/deny permissions. `router init --executor codex` selects an exact `openai/model-id` and an explicit sandbox. `router init --executor claude` selects an exact `anthropic/claude-family-version` and explicit `tools`/`allow` lists for noninteractive `dontAsk` permissions. Each executor retains its approved authentication. Hooks never download packages, start a daemon, or grant permissions.

Hooks execute the installed runtime in Python's isolated mode, not a second copy of the package from the plugin cache. Only configured delegation projects receive instruction IDs; unconfigured projects remain observation-only. The bootstrap interpreter pointer stays in the default bootstrap directory even when advanced environment configuration moves data state.

The hooks forward lifecycle metadata only; Router does not read native transcripts or retain native assistant output. Router retains metadata, task instructions for external children, execution artifacts, and history in its private state directory. The native observer does not retain prompt bodies. Retained text is kept as written: Router strips terminal control sequences and bounds length, but does not scan it for secrets, so keep the state directory private. It does not upload telemetry. External work uses your configured provider and credentials; worktrees are not security sandboxes. Codex uses its saved CLI login and approved read-only or workspace-write sandbox, ignoring Router provider-key/endpoint overrides. OpenCode and Claude children can read or modify host-user files according to their permissions. Claude uses its normal CLI authentication, safe mode, and a persisted native session for parent-requested corrections; it refuses uninspected executables, unsupported CLI versions, or mismatched model/session evidence. Claude cost is the aggregate native CLI estimate, with cumulative usage converted to attempt deltas. Codex cost is a standard short-context input/cache-read/cache-write/output token estimate using the configured model; it excludes tool fees and long-context premiums. Costs are estimates, not bills, and missing data stays unknown.

`router status --watch` opens the single-host terminal view. With `~/.agent-router/fleet.toml` configured on a viewing machine, `router fleet status --watch` pulls read-only snapshots from local and SSH hosts. Fleet monitoring does not dispatch, schedule, stop, or mutate work; unavailable hosts remain explicit. `router uninstall` removes the user plugin and managed service but retains local configuration and history. On Linux the daemon is started manually; Windows is unsupported. This integration targets local Claude Code sessions, not ordinary Claude chat.
